# 🔒 SecureVote — Криптографиялық электронды дауыс беру жүйесі

> **Python 3 · Flask · SQLite · Cryptography · Argon2id · AES-256-GCM · Ed25519 · SHA-256**

SecureVote — бұл криптография пәнінен модульдік жобалар мен дипломдық зерттеулерге арналған, толыққанды, математикалық тұрғыдан дәлелденген криптографиялық электронды дауыс беру прототипі. Жобада шаблондық немесе сыртқы жасанды жазулар емес, **шынайы жұмыс істейтін криптографиялық алгоритмдер** іске асырылған.

## 📑 Жобаның құрылымы (Frontend & Backend бөлінісі)

Жобаның сұранысқа сәйкес **backend** (сервер, деректер базасы, криптография және тесттер) және **frontend** (интерфейс, шаблондар, стильдер, скрипттер) бөліктері нақты бөлінген:

```text
CryptoVote/
├── run.py                     # Жобаны бірден іске қосу нүктесі (Root Launcher)
├── requirements.txt           # Тәуелділіктер тізімі
├── README.md                  # Толық техникалық құжаттама және қорғау нұсқаулығы
│
├── backend/                   # ⚙️ БЭКЕНД ЖӘНЕ КРИПТОГРАФИЯ БӨЛІМІ
│   ├── app.py                 # Flask сервері, сессиялар, маршруттар және REST API
│   ├── config.py              # Қауіпсіздік және папкалар конфигурациясы
│   │
│   ├── crypto/                # 🛡️ НЕГІЗГІ КРИПТОГРАФИЯЛЫҚ МОДУЛЬДЕР
│   │   ├── passwords.py       # Argon2id: Құпиясөздерді қауіпсіз хэштеу
│   │   ├── encryption.py      # AES-256-GCM: Дауыстарды аутентификацияланған шифрлау
│   │   ├── signatures.py      # Ed25519: Эллиптикалық цифрлық қолтаңбалар
│   │   └── audit.py           # SHA-256: Бұрмалауға қарсы блокчейн-хэш тізбегі
│   │
│   ├── voting/                # 🗳️ САЙЛАУДЫҢ БИЗНЕС-ЛОГИКАСЫ
│   │   ├── authentication.py  # Пайдаланушыларды тексеру және тіркеу

│   ├── database/              # 🗄️ ДЕРЕКТЕР БАЗАСЫ (SQLite)
│   │   ├── db.py              # Қосылу, транзакциялар, автоматты seed деректері

│   │   └── securevote.db      # SQLite дерекқоры файлы
│   │
│   └── tests/                 # 🧪 АВТОМАТТЫ ТЕСТТЕР ЖИНАҒЫ (Pytest)
│       ├── test_crypto.py     # Argon2id, AES-256-GCM, Ed25519 тесттері
│       ├── test_audit.py      # SHA-256 тізбегі және бұрмалауды анықтау тесттері
│       └── test_voting.py     # 1-сайлаушы 1-дауыс және қорытындылау тесттері
```

## 🔬 Криптографиялық механизмдердің сипаттамасы

| Механизм | Қолданылған алгоритм | Не үшін қажет? | Тәжірибелік артықшылығы |
| :--- | :--- | :--- | :--- |
| **Құпиясөз қорғанысы** | **Argon2id** (OWASP) | Құпиясөздерді ашық түрде сақтамау | Жадқа тәуелді (Memory-hard), GPU/ASIC және Side-Channel шабуылдарына төзімді. |
| **Дауысты шифрлау** | **AES-256-GCM** | Дауыс мазмұнының құпиялылығы мен тұтастығы | Authenticated Encryption (AEAD). 12-байттық IV және 16-байттық GHASH тегі бар. Шифрмәтіннің 1 биті өзгерсе, ашу мүмкін емес (`InvalidTag`). |
| **Аудит тізбегі** | **SHA-256 Merkle Chain** | Дауыс жазбаларының өзгертілмегенін тексеру | Әрбір жазба $H_i = \text{SHA256}(i \parallel ts \parallel H_{i-1} \parallel \text{action} \parallel \text{data})$ арқылы алдыңғы блокқа байланысқан. |
| **Цифрлық қолтаңба** | **Ed25519** | Аудит жазбалары мен нәтиженің авторлығы | Curve25519 эллиптикалық қисығындағы EdDSA алгоритмі. Жоғары жылдамдық және детерминистік қауіпсіздік. |
| **Кездейсоқ мәндер** | **`secrets` (CSPRNG)** | Болжап табу қиын токендер жасау | ОЖ ядросының криптографиялық энтропия көзінен алынады. |
| **Анонимділік (Unlinkability)** | **HMAC-SHA256 Nullifier** | Сайлаушының жеке басын дауыстан ажырату | `votes` кестесінде `voter_id` сақталмайды. Сайлаушының бірегей тұзынан сайлау идентификаторына байланысты 1 реттік нуллификатор есептеледі. |

## 🚀 Жобаны жергілікті компьютерде іске қосу

### 1. Тәуелділіктерді орнату
Виртуалды ортаны іске қосып, кітапханаларды орнатыңыз:
```bash
# Windows жүйесінде:
py -m pip install -r requirements.txt
```

### 2. Серверді іске қосу
Жобаның негізгі папкасынан:
```bash
py run.py
```
Сервер жұмысын бастайды: **`http://127.0.0.1:5000`** браузер арқылы ашыңыз.

## 🧪 Автоматты тесттерді іске қосу

Жоба барлық криптографиялық қасиеттердің нақты жұмыс істейтінін растайтын автоматты тестілеу жинағымен қамтылған:
```bash
.\.venv\Scripts\pytest -v backend/tests
```
**Сынақтан өтетін сценарийлер:**
1. `test_argon2id_password_hashing`: Құпиясөзді дұрыс тексеру және қате құпиясөзді бұғаттау.
2. `test_aes_256_gcm_encryption_roundtrip`: Дауысты толық дұрыс шифрлау және ашу.
3. `test_aes_256_gcm_tamper_detection`: Шифрмәтіннен 1 байтты әдейі өзгерткенде `InvalidTag` қатесінің шығуы.
4. `test_ed25519_signatures`: Цифрлық қолтаңбаның түпнұсқалығын растау және бұрмаланған хабарламаны қабылдамау.
5. `test_sha256_hashing_and_nullifiers`: Нуллификатордың бірегейлігі мен хэштеу тұрақтылығы.
6. `test_audit_chain_integrity_and_tamper_detection`: Аудит тізбегіндегі кез келген блоктың өзгеруін лезде анықтау.
7. `test_first_vote_succeeds_and_prevents_double_voting`: Сайлаушының бірінші дауысы қабылданып, **екінші дауыс беру әрекеті қатаң бұғатталуы**.
8. `test_cannot_vote_in_closed_election`: Жабық сайлауға дауыс беруге тыйым салу.
9. `test_full_tally_and_verification`: Барлық дауыстарды қайта есептеу, Ed25519 арқылы қолтаңбалау және тексеру.

## 🎓 Оқытушыға қорғау кезіндегі сұрақтар мен жауаптар (Defense FAQ)

### 1-сұрақ: «SHA-256 хэштеу мен AES-256 шифрлаудың айырмашылығы неде?»
> **Жауап:** SHA-256 — бұл **бірбағытты хэш-функция** (One-Way Hash Function). Одан бастапқы дауысты кері ашу мүмкін емес, ол тек деректердің тұтастығын (өзгермегенін) тексеру үшін қолданылады. Ал AES-256-GCM — бұл **екібағытты симметриялық шифрлау**. Ол сайлау барысында дауыс құпиялылығын сақтап, сайлау біткен соң рұқсат етілген кілтпен ашып, нәтижені есептеуге мүмкіндік береді.

### 2-сұрақ: «Сайлаушының кімге дауыс бергенін әкімші қалай біле алмайды?»
> **Жауап:** Архитектуралық тұрғыдан сайлаушының кім екенін тіркейтін кесте (`voter_participation`) мен шифрланған дауыстар сақталатын кесте (`votes`) **толық ажыратылған** (Decoupled). `votes` кестесінде `user_id` жоқ! Оның орнына `nullifier = HMAC-SHA256(voter_salt, election_id)` қолданылады. Бұл бір адамның екі рет дауыс беруіне жол бермейді, бірақ дауыстың нақты қай адамға тиесілі екенін жасырады.

### 3-сұрақ: «AES-256-GCM алгоритмінің қарапайым AES-CBC немесе ECB-дан қандай айырмашылығы бар?»
> **Жауап:** GCM режимі — бұл **AEAD (Authenticated Encryption with Associated Data)**. Ол тек шифрлап қана қоймайды, сонымен бірге 16 байттық Galois/Counter Authentication Tag шығарады. Егер шабуылдаушы шифрмәтіннің 1 байтын өзгертсе (bit-flipping attack), жүйе оны дешифрлеу кезінде бірден анықтап, қате (`InvalidTag`) береді.

### 4-сұрақ: «Аудит тізбегінде Ed25519 цифрлық қолтаңбасы не үшін қажет?»
> **Жауап:** Егер жай ғана SHA-256 тізбегі болса, дерекқорға рұқсаты бар шабуылдаушы бір блокты өзгертіп, барлық кейінгі блоктардың хэшін қайта есептеп шығуы мүмкін. Ал Ed25519 қолтаңбасы әр блокты сайлау комиссиясының жабық кілтімен бекітеді. Жабық кілтсіз шабуылдаушы жаңа блок жасай алмайды.
